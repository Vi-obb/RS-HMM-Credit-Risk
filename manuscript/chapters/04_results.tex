\chapter{Results}

This chapter presents the empirical result structure for the Freddie Mac mortgage PD study. It organizes the outputs from the loan-level panel, the macro regime model, and the three-model logistic comparison.

\section{Results Structure}

The final empirical results chapter should report four layers of evidence:

\begin{itemize}
    \item descriptive summaries of the mortgage panel and macro sample overlap
    \item the inferred macro regime path and stress probabilities from the HMM
    \item comparative model results for the borrower-only, macro-augmented, and regime-aware logistic models
    \item calibration-focused diagnostics by time period and macro regime
\end{itemize}

\section{Tables And Figures}

The output set includes:

\begin{itemize}
    \item a data coverage table for Freddie Mac cohorts and usable loan-month observations
    \item a figure showing the macro regime path and filtered stress probability
    \item a model comparison table with Brier score, ROC-AUC, PR-AUC, and log loss
    \item calibration plots for each model on the held-out period
    \item regime-slice and time-slice evaluation tables
\end{itemize}

\section{Interpretation Focus}

The chapter is not organized around prediction accuracy alone. The main interpretation goal is to determine whether the regime-aware logit produces more reliable default probabilities, especially during macro stress and transition periods.

\section{Current Archive Status}

Synthetic figures and synthetic performance tables from the earlier repository phase are archived and are not part of the active thesis evidence. Active results belong to the Freddie Mac workflow.
