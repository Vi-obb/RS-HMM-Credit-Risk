\chapter{Conclusion}

This thesis studies an empirical Freddie Mac plus FRED model for regime-aware mortgage PD estimation. The active contribution is an interpretable logistic framework that uses an HMM-derived macro stress probability to capture changing borrower sensitivities across macro conditions.

\section{Expected Contribution}

The thesis contributes a clear comparison between borrower-only, macro-augmented, and regime-aware logistic PD models in a mortgage setting, with calibration treated as a primary outcome rather than an afterthought.

\section{Main Limitation At This Stage}

The repository centers on the mortgage PD study and retains the archived synthetic scaffold only as background material. The active implementation path is the Freddie Mac workflow.

\section{Next Steps}

The next implementation steps are:

\begin{itemize}
    \item Freddie Mac origination and servicing ingestion
    \item loan-month panel construction and label definition
    \item macro HMM estimation using FRED inflation, Fed Funds, and unemployment
    \item three-model logistic comparison with chronological validation
    \item calibration-first results reporting
\end{itemize}

That sequence defines the active path for the thesis workflow.
