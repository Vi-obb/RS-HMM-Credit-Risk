\chapter{Conclusion}

This thesis studies an empirical Freddie Mac plus FRED model for regime-aware mortgage PD estimation. The active contribution is an interpretable logistic framework that uses an HMM-derived macro stress probability to capture changing borrower sensitivities across macro conditions.

\section{Expected Contribution}

The thesis contributes a clear comparison between borrower-only, macro-augmented, and regime-aware logistic PD models in a mortgage setting, with calibration treated as a primary outcome rather than an afterthought. The current empirical pass strengthens the evidence base by using a mortgage-window HMM, forward-filtered stress probabilities, validation-based regularization tuning, and validation-based probability calibration.

\section{Main Finding And Limitation}

The current result is mixed. The clean regime-aware logit slightly improves held-out Brier score and calibration-bin reliability relative to the borrower-only benchmark, but the borrower-only model still has the best held-out log loss. The lagged-stress regime-aware variant improves ROC-AUC, but it worsens Brier score and log loss. The HMM stress signal is therefore useful as an interpretable macro-risk layer, but the evidence does not support a broad claim that regime awareness dominates borrower-only underwriting variables as a PD model.

The main diagnostic limitation is regime-slice evaluation. Under the 0.50 hard-stress threshold, the held-out test period is entirely classified as stress, so the current regime-slice table does not provide a meaningful normal-versus-stress contrast. Future reporting should use quantile or continuous stress-probability slices before making strong claims about performance across regimes.

\section{Next Steps}

The next implementation steps are:

\begin{itemize}
    \item update regime-slice reporting to use quantile or continuous stress-probability bins
    \item run a focused robustness pass with baseline, clean regime-aware, and a smaller dynamic-stress specification
    \item test calibration sensitivity, especially Platt scaling versus intercept-only recalibration
    \item keep the thesis claim calibration-first and avoid presenting the regime-aware layer as a guaranteed accuracy improvement
\end{itemize}

That sequence defines the remaining refinement path for the thesis workflow.
