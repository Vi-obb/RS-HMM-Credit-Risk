\section{Loan-Month Outcome and Risk Set}

The unit of analysis is an eligible loan at calendar month $t$. The target $Y_{i,t}^{(12)}$ equals one when loan $i$ first reaches at least 90 days past due in one of months $t+1$ through $t+12$. A row is retained only when the loan is not already at least 90 days past due at $t$ and the complete twelve-month outcome window is observable. Rows after the first qualifying event do not re-enter the risk set. All payment-history features use information through month $t$ only.

\chapter{Frozen Model and Validation Protocol}
\label{app:model-protocol}

\section{Core Specifications}

Let $X_{i,t}$ contain the 32 variables in Table~\ref{tab:loan-data-dictionary}, after training-window standardisation and median imputation in the fitted pipeline. The three frozen specifications were:

\begin{align}
\operatorname{logit}(\pi^{B}_{i,t})
  &= \beta_0 + X_{i,t}^{\top}\beta,\\
\operatorname{logit}(\pi^{M}_{i,t})
  &= \gamma_0 + X_{i,t}^{\top}\gamma + M_t^{\top}\delta,\\
\operatorname{logit}(\pi^{R}_{i,t})
  &= \alpha_0 + X_{i,t}^{\top}\alpha + \eta q_t
     + \sum_{j\in\mathcal{J}}\theta_j q_t X_{i,t,j}.
\end{align}

The interaction set $\mathcal{J}$ comprised credit score, original combined LTV, original DTI, original LTV, original interest rate, current delinquency months, recent 60-DPD status over three months, and months since 30 DPD. All models were regularised logistic regressions fitted with deterministic settings. No black-box model, new threshold, or post-test feature search entered the freeze pass.

\section{HMM Initialisation Audit}

The selected seeds were 101, 71, and 71 at the three origins. At origin 2021-04, starts 23 and 71 were invalid because one transition-matrix row had no outgoing transition and therefore did not sum to one. They were excluded before selection. The other three starts at that origin and all five starts at the later origins produced valid transition matrices. Selection used training log likelihood only; validation and test defaults did not enter HMM selection.

The extreme stress shares in the three test windows were 1.0000, 1.0000, and 0.9167. The corresponding hard-stress shares were 0.0833, 1.0000, and 0.6667. Mean binary entropy was effectively zero in the first two tests and 0.0376 in the third. These diagnostics support use of the state as a sharply classified period indicator while limiting continuous-probability and hard-regime comparisons.

\section{Paired Temporal Uncertainty}

Monthly borrower-only and regime-aware losses were paired before resampling. Ten thousand deterministic moving-block replicates sampled blocks of three consecutive months. The regime-aware-minus-borrower-only Brier estimate was 0.0000869 with a 95\% interval of $[-0.0001558,0.0002714]$; 25.18\% of replicates favoured regime-aware. The log-loss estimate was 0.0018573 with interval $[-0.0008756,0.0040205]$; 8.76\% favoured regime-aware. These are uncertainty summaries for temporal test blocks, not confidence intervals for a universal population parameter.

\section{Execution Boundary}

The freeze pass is implemented in \texttt{src/rs\_hmm/rolling\_freeze.py} and invoked by \texttt{scripts/run\_rolling\_freeze.py}. The data-bearing execution used the repository's existing empirical inputs and fixed model definitions. No test outcome was used to change model families, interaction lists, thresholds, HMM state count, covariance form, or calibration method.

The worktree used to prepare this document does not contain the large ignored raw and processed datasets. The verified empirical run was therefore executed in the data-bearing primary checkout at \texttt{/Users/theboyyy/Work/Research/RS-HMM-Credit-Risk}. This is an environment-location limitation, not a difference in tracked code. The resulting tables were regenerated twice, and all eleven CSV artefacts were byte-identical across the two runs.

\section{Commands}

From a configured data-bearing checkout, the frozen run is invoked with:

\begin{verbatim}
python scripts/run_rolling_freeze.py
\end{verbatim}

The focused and full automated checks are:

\begin{verbatim}
pytest -q tests/test_rolling_freeze.py
pytest -q
\end{verbatim}

The verified full suite reported 27 passing tests. The deterministic SGD fits emitted fixed-iteration convergence warnings at the configured 30 iterations; they completed and reproduced byte-identical result artefacts. Those warnings should be retained in the execution record and not misreported as failed fits.

The thesis PDF is compiled from the \texttt{manuscript} directory using the approved isolated TeX Live procedure documented with the project. Bibliographic processing is included in that compilation sequence.

\section{Reproduction Checklist}

An independent reproduction should verify the input file inventory and hashes; confirm the 2015--2024 cohort selection; rebuild payment-history variables in loan and month order; check that every outcome has complete forward follow-up; inspect chronological split boundaries; confirm that scalers and HMM parameters are training-only at each origin; compare selected HMM seeds and likelihoods; fit the three frozen logistic models; fit Platt calibration only on validation; and compare all eleven CSV artefacts. A substantive replication should additionally document software versions, processor architecture, and any numerical-library differences.
